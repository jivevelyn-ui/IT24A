CHICKENVERSE WEBSITE

Files:
- index.html: structure and page content
- style.css: colors, layout, responsive styling
- script.js: navigation highlight and Leaflet map
- images/uncle-johns.jpg: image supplied by the user

HOW TO RUN:
1. Extract the ZIP file.
2. Open the chickenverse-website folder in VS Code.
3. Open index.html with Live Server (recommended).
4. Keep an internet connection active for the remote food photos, Google Fonts, and Leaflet map tiles.

NOTES:
- The other five photos are illustrative remote food images, not official brand photos.
- The map coordinates are an example location in Manolo Fortich, Bukidnon. Change them in script.js to the location you choose.
- Chickenverse is a fictional school project. The featured brand names belong to their respective owners.
